# Smart Support Hub

Веб-платформа внедрения, эксплуатации и сопровождения программного продукта.

## Возможности
- Панель мониторинга с KPI-показателями и графиками Chart.js.
- Учёт этапов внедрения у заказчиков (`planning`, `setup`, `training`, `production`).
- Регистрация инцидентов, фильтр по статусу и автоматический расчёт SLA.
- Ведение заявок на сопровождение четырёх видов (`corrective`, `adaptive`, `perfective`, `preventive`).
- Управление версиями (SemVer) и история релизов.
- Сохранение данных и выбранной темы оформления в `localStorage`.

## Запуск
Откройте `index.html` через VS Code Live Server или перейдите по ссылке GitHub Pages.
