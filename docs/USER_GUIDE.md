# Руководство пользователя

## Назначение
Платформа **Smart Support Hub** предназначена для команды поддержки и сопровождения программного продукта: отслеживания внедрений, обработки инцидентов по SLA и планирования обновлений.

## Как зарегистрировать инцидент
1. Перейдите в раздел **Инциденты** в левом меню.
2. Введите описание проблемы в поле ввода и выберите приоритет (`critical`, `high`, `medium`, `low`).
3. Нажмите кнопку **Создать инцидент**. Система автоматически рассчитает срок SLA.

## Как создать заявку на изменение
1. Откройте раздел **Заявки**.
2. Укажите суть доработки, выберите вид сопровождения (`corrective`, `adaptive`, `perfective`, `preventive`) и целевую версию.
3. Нажмите **Создать заявку**.

## Куда обратиться
При возникновении вопросов по работе платформы создайте обращение в разделе **Issues** репозитория проекта на GitHub.
